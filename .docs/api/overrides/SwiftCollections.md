The Unity boundary includes explicit conversion from `UnityEngine.Bounds` to
SwiftCollections floating-point and FixedMathSharp-backed query volumes.

For the engine-agnostic collection and query contracts, browse the
[SwiftCollections core API](https://mrdav30.github.io/SwiftCollections/).
Fixed-point primitives and conversions are owned by the
[FixedMathSharp core API](https://mrdav30.github.io/FixedMathSharp/).
