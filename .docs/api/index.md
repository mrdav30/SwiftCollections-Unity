# SwiftCollections for Unity Documentation

SwiftCollections for Unity provides Unity serialization, pooling, bounds, and
FixedMathSharp query adapters for the engine-agnostic SwiftCollections library.

- [Browse the Unity serialization adapters](xref:SwiftCollections.Unity)
- [Browse the GameObject pool API](xref:SwiftCollections.Pool)
- [Browse the Unity bounds adapters](xref:SwiftCollections.BoundVolumeExtensions)
- [Browse the FixedMathSharp query adapters](xref:SwiftCollections.FixedBoundVolumeExtensions)
- [Read the SwiftCollections core API](https://mrdav30.github.io/SwiftCollections/)
- [Read the FixedMathSharp core API](https://mrdav30.github.io/FixedMathSharp/)
- [Choose and install a Unity package](https://github.com/mrdav30/SwiftCollections-Unity#packages)

Keep runtime collection state in SwiftCollections types. Use the Unity adapters
for authoring data and engine-boundary conversions.
